Mac setup

Why this exists

Every so often I get a new Mac, or wipe one and start over, and setting everything up again used to take an afternoon: installing tools and apps, signing in to everything, digging up keys.

So I turned it into one command. Now I only need to remember this address: open it, copy the line below, and paste it into Terminal.

If you landed here by accident: hi 👋. This is my personal setup, so it installs my tools and only works with my accounts.

curl -fsSL https://setup.jasielrivera.com | bash

Terminal is in Applications → Utilities, or press ⌘ Space and type “Terminal”.

What happens

  1. Confirmation: type yes to go on.
  2. Apple's command line tools: a window pops up; click Install and wait (a few minutes).
  3. Homebrew: asks for the Mac's password once.
  4. Claude Code and Codex: installed right away, so a coding agent can help (here or in a remote session) if anything later goes wrong. Run claude to sign in.
  5. GitHub: shows a one-time code and opens the browser to sign in.
  6. Private setup repo is cloned to ~/Developer/mac-setup.
  7. Guided setup: asks what kind of Mac this is (see below), then goes step by step.

Have these ready

  • The Mac's password (for Homebrew).
  • GitHub login (and phone for 2FA).
  • The password manager: the guided setup asks for the Infisical machine identity (client ID and secret) once, to restore the infra keys.
  • About 30–60 minutes, mostly downloads.

Kinds of Mac

WorkstationCommand-line tools only.
Workstation with appsTools plus my desktop apps (editors, browsers, AI apps, Docker…). The default.
Home serverTools plus OrbStack, never-sleep power settings, and a short checklist (Tailscale sign-in, Remote Login, Screen Sharing, router reservation, FileVault).

Afterwards

~/Developer/mac-setup/setup.sh --checkSee what's done and what's missing. Changes nothing.
~/Developer/mac-setup/setup.sh --guidedRun the guided setup again (safe; done steps are skipped).
~/Developer/mac-setup/setup.sh secretsRun a single step (homebrew, packages, shell, git, ssh, secrets, coolify, repos, server).

If something goes wrong

  • Stopped at the command line tools: finish the Install window, then run the command again.
  • “brew: command not found” in a new window: open a new Terminal window (the setup adds Homebrew to ~/.zprofile).
  • GitHub sign-in failed: run gh auth login --web, then the command again.
  • Can't reach the server over SSH: the ssh step prints the one command to run from a Mac that already has access.
  • Try it without changing anything: curl -fsSL https://setup.jasielrivera.com | BOOTSTRAP_NO_RUN=1 bash stops before the guided setup.
